# PWA 添加到桌面说明

「植迹」已配置为 PWA（渐进式 Web 应用），可像原生 App 一样添加到手机/电脑桌面，打开后全屏运行、接近原生体验。

## iOS（Safari）

1. 用 **Safari** 浏览器打开「植迹」的在线地址（注意：iOS 仅 Safari 支持添加 PWA）
2. 点击底部中间「**分享**」按钮（方形带向上箭头的图标）
3. 向下滑动菜单，找到并点击「**添加到主屏幕**」
4. 确认名称（可自定义），点击右上角「**添加**」
5. 桌面会出现「植迹」图标，点击即可全屏打开

## Android（Chrome）

1. 用 **Chrome** 浏览器打开「植迹」的在线地址
2. 点击右上角「**⋮**」（三个点）菜单
3. 点击「**安装应用**」或「**添加到主屏幕**」（不同版本名称略有差异）
4. 弹窗中点击「**安装**」
5. 桌面/应用列表会出现「植迹」图标

> 部分 Android 浏览器会在首次访问时自动弹出「添加到主屏幕」的提示横幅，直接点「添加」即可。

## 电脑（Chrome / Edge）

1. 用 Chrome 或 Edge 打开在线地址
2. 地址栏右侧会出现「安装」图标（或 ⋮ 菜单中的「安装 植迹」）
3. 点击「安装」
4. 应用会以独立窗口形式运行

---

## 离线支持说明

已加载过的页面和图片会被 Service Worker 缓存，**弱网或断网时仍可查看已访问过的内容**。但新增/编辑操作需要网络连接（数据需同步到云端）。

## 图标与启动画面

- 应用图标：苔绿色背景 + 白色叶子图形（192px / 512px）
- 启动画面：白色背景 + 图标 + 应用名「植迹」
