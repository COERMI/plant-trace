# 部署说明（Vercel 正式部署）

> 项目代码已完成首次 commit（`master` 分支，作者 COERMI）。下面按顺序操作即可上线，得到一个永久 `https://xxx.vercel.app` 在线地址。

---

## 一、前提：先确认 Supabase 已配置好

部署前请确保你已完成：
1. 已在 Supabase 创建项目，并在 **SQL Editor** 里运行过 `supabase/schema.sql`（建表 + RLS + 存储桶）
2. 已拿到两个值：
   - **Project URL**（形如 `https://xxxx.supabase.co`）
   - **anon public key**（一长串，以 `eyJ...` 开头）

这两个值当前已写在本项目的 `.env` 文件里（已被 `.gitignore` 保护，不会上传）。部署时需要在 Vercel 里再填一次。

---

## 二、把代码推到 GitHub（Vercel 从 GitHub 拉取）

Vercel 网页端最顺滑的方式是直接连你的 GitHub 仓库，所以先把本地代码推上去。

### 1. 在 GitHub 网页创建一个空仓库
1. 打开 [github.com/new](https://github.com/new)
2. Repository name 填：`plant-trace`（或你想用的名字，建议与「植迹」对应）
3. 选 **Private** 或 Public 都可以
4. **不要**勾选 "Add a README / .gitignore / license"（保持空仓库）
5. 点「Create repository」

### 2. 本地推送
创建后 GitHub 会显示一段命令，或者直接在你的终端（项目根目录）运行：

```bash
cd "C:/Users/user/WorkBuddy/盆多多-个人植物记录app"

# 把远程仓库指向你的仓库（把 COERMI/plant-trace 换成你的实际仓库名）
git remote add origin https://github.com/COERMI/plant-trace.git

# 推送
git push -u origin master
```

> 如果提示登录，用你的 GitHub 账号（COERMI）登录即可。首次推送可能需要个人访问令牌（Personal Access Token）代替密码——这是 GitHub 从 2021 年起的安全要求，密码处粘贴 token 即可。

---

## 三、部署到 Vercel

### 1. 导入仓库
1. 打开 [vercel.com](https://vercel.com)，点「Sign Up」用 **GitHub 账号登录**（授权访问你的仓库）
2. 点「Add New」→「Project」
3. 在列表里找到你刚推送的仓库（如 `plant-trace`），点「Import」

### 2. 配置构建设置（一般自动识别，无需改）
- Framework Preset：会自动识别为 **Vite**
- Build Command：`npm run build`
- Output Directory：`dist`

### 3. 配置环境变量（关键！）
在「Environment Variables」区域添加两个变量：

| 名称 | 值 |
|------|-----|
| `VITE_SUPABASE_URL` | 你的 Supabase Project URL（`https://xxxx.supabase.co`） |
| `VITE_SUPABASE_ANON_KEY` | 你的 anon public key（`eyJ...` 开头） |

> 两个值和你本地 `.env` 里的一模一样。`VITE_` 前缀的变量会在构建时注入前端代码，必须填对。

### 4. 部署
点「Deploy」，等待 1-2 分钟构建完成。

部署成功后会得到一个 `https://xxx.vercel.app` 地址，**点击即可在线访问**。

## 四、验证 PWA（手机添加到桌面）

部署成功后，用手机浏览器打开 `https://xxx.vercel.app`：

### iOS（Safari）
1. 用 **Safari** 打开网址（不要用微信内置浏览器）
2. 点底部中间的「分享」按钮（方形带向上箭头）
3. 往下滑，点「**添加到主屏幕**」（Add to Home Screen）
4. 确认名称，点「添加」
5. 桌面会出现「植迹」图标，点开即全屏应用

> 需要站点已通过 HTTPS 且 manifest 正常（Vercel 自动 HTTPS，已满足）。

### Android（Chrome）
1. 用 **Chrome** 打开网址
2. 点右上角「⋮」菜单
3. 点「**安装应用**」或「添加到主屏幕」（Add to Home Screen）
4. 点「安装」
5. 桌面出现应用图标，点开即独立窗口运行

## 五、后续更新代码怎么重新部署

Vercel 已和你的 GitHub 仓库绑定，之后**每次 push 会自动触发重新部署**，无需手动操作：

1. 本地改完代码
2. `git add -A && git commit -m "描述这次改动"`
3. `git push`
4. Vercel 检测到新提交 → 自动构建 → 新版本上线（同一网址）

也可以进 Vercel 项目面板的「Deployments」页，点某个历史版本「⋯」→「Redeploy」回滚或重发。

4. 刷新页面，数据不丢失
5. 手机打开同一地址登录同一账号，数据同步
6. 手机「添加到主屏幕」成功，图标显示为叶子

## 七、注意事项

- 免费版 Supabase 7 天无访问会暂停项目，长期使用建议定期访问或升级
- 免费版存储约 1GB，图片已前端压缩，正常够用
- `.env` 不会被提交到 GitHub（密钥安全），Vercel 里的环境变量是独立的、私密的
- 如果换了 Supabase 项目，需同时更新 Vercel 环境变量并重新部署
