# 部署说明

## 一、配置 Supabase（后端）

### 1. 创建项目
1. 打开 [supabase.com](https://supabase.com)，用 GitHub 或邮箱注册
2. 点击「New project」，填写项目名（如 `planttrace`）、设置数据库密码、选择区域（建议选择离你近的区域，如 `Southeast Asia (Singapore)`）
3. 等待项目初始化完成（约 1-2 分钟）

### 2. 初始化数据库
1. 左侧菜单点击「SQL Editor」
2. 点击「New query」
3. 打开本项目 `supabase/schema.sql`，复制全部内容粘贴进去
4. 点击「Run」运行

这会创建：
- `plants` 表（植物档案）
- `records` 表（生长记录）
- 行级安全策略（RLS，用户只能访问自己的数据）
- `plant-images` 存储桶及存储策略

### 3. 获取连接信息
1. 左侧菜单点击「Project Settings」→「API」
2. 复制两个值：
   - **Project URL**（形如 `https://xxxx.supabase.co`）
   - **anon public key**（一长串，以 `eyJ...` 开头）

### 4. 关闭邮箱验证（可选，方便测试）
若注册后收不到确认邮件想直接登录，可在「Authentication → Providers → Email」中关闭「Confirm email」。生产环境建议保持开启。

## 二、部署到 Vercel（推荐）

### 准备代码仓库
1. 将本项目推送到 GitHub（或直接用 Vercel CLI 部署）

### 部署步骤
1. 打开 [vercel.com](https://vercel.com)，用 GitHub 登录
2. 点击「Add New」→「Project」
3. 导入你的仓库
4. 框架会自动识别为 Vite，无需修改构建设置（Build Command: `npm run build`，Output: `dist`）
5. 在「Environment Variables」中添加两个变量：
   - `VITE_SUPABASE_URL` = 你的 Project URL
   - `VITE_SUPABASE_ANON_KEY` = 你的 anon key
6. 点击「Deploy」

部署完成后会得到一个 `https://xxx.vercel.app` 的在线地址。

---

## 三、部署到 Netlify（备选）

1. 打开 [netlify.com](https://netlify.com)，用 GitHub 登录
2. 点击「Add new site」→「Import an existing project」
3. 选择仓库
4. 构建设置：
   - Build command: `npm run build`
   - Publish directory: `dist`
5. 在「Environment variables」中添加 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`
6. 点击「Deploy site」

---

## 四、验证

部署完成后：
1. 打开在线地址，确认能正常注册/登录
2. 新增一株植物并上传封面图
3. 新增一条生长记录并上传照片
4. 刷新页面，确认数据不丢失
5. 用手机打开同一地址，登录同一账号，确认数据同步

## 五、注意事项

- 免费版 Supabase 有暂停策略（7 天无访问会暂停项目），如长期使用建议定期访问或升级
- 免费版存储空间约 1GB，图片已做前端压缩，正常使用足够
- 环境变量中 `VITE_` 前缀的变量会在构建时注入前端代码，必须配置正确才能连接后端
