# 使用说明

## 一、注册 / 登录

首次使用打开应用，会看到登录页。切换到「注册」标签，输入邮箱和密码（至少 6 位），点击「注册并登录」即可开始使用。之后打开同一地址会自动登录。

> 数据仅保存在你自己的账号中，换设备用同一邮箱登录即可看到相同数据。

## 二、新增植物（3 步内完成）

1. 在首页点击右下角「+」按钮
2. 上传封面图 → 填写植物名称（必填）→ 可选填品类 / 品系 / 品种 / 入手渠道 / 当前状态 / 备注
3. 点击「保存」

> 品类、品系、品种输入时会自动联想已使用过的标签，方便统一分类。

## 三、查看植物详情

点击首页任意植物卡片，进入详情页，可看到：

- 顶部封面大图 + 植物名称 + 标签 + 入手信息
- 基础信息（来源、当前状态、备注）
- 各事件类型累计次数统计
- 倒序生长时间线（最新在最上方）

## 四、新增生长记录（3 步内完成）

1. 在详情页点击右下角「+」按钮
2. 选择事件类型（入手 / 浇水 / 施肥 / 换盆 / 修剪 / 发芽 / 开花 / 病虫害 / 其他）→ 可选上传照片（最多 9 张）→ 可选填备注
3. 点击「保存」

## 五、编辑 / 删除

- **编辑植物**：详情页右上角「编辑」按钮
- **编辑记录**：记录卡片底部「编辑」按钮
- **删除**：编辑模式下有红色「删除」按钮，会二次确认。删除植物会连带删除其所有记录。

## 六、数据同步

所有数据实时保存在云端（Supabase），电脑和手机打开同一地址、登录同一账号，数据自动同步一致。

图片上传前会在浏览器端自动压缩（宽最大 1200px，质量 80%），节省存储空间。
